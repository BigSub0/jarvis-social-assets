# Venue photos

Real stadium/arena photos used as the card hero background.

Rules:
- Venue/building/field shots ONLY. No players, people as the subject, team logos, or wordmarks as the focus.
- Only freely licensed images that allow commercial use: CC0, public domain, CC BY, or CC BY-SA (e.g. from Wikimedia Commons). Never Getty/AP/Imagn/team/league photos, even if "already published".
- File name: `<venue-slug>.jpg` (e.g. `tropicana-field.jpg`), resized to ~1600px wide.
- Every file must have an entry in `credits.json`: {"<venue-slug>": {"author": "...", "license": "CC BY-SA 4.0", "source": "<Commons file page URL>"}}.
- The card's credit line reads: `Photo: <author> · <license> · Wikimedia Commons`.
